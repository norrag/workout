workout — design exploration 03 · revision pass

Ledger system, rev. 2

Pump & workload are snap-to-stop sliders (no numbers — endpoints + ⓘ explainers). Set types: straight + drop. MESOS is now CYCLES, with macros as the expandable spine. The planner is now groups-first: lay out muscle groups and exercise counts for the day in one batch (2.5 Day setup — which also holds the day tools: label, weekday, week-start, remove), then fill each slot from a picker pre-filtered to that group with last-performed and history in view (2.6). Workout complete gains a free-text notes field, saved with the session for the AI connector and later analysis. Create-meso keeps the macro placement timeline; units live in Settings. Orange budget unchanged: current position + selected states only. Round 4: meso stats — volume, balance, performance — behind a stats button on meso detail; the More tab with profile & inline settings; and a full unit sweep to lb.

next steps
  • ✓ Confirmed: groups-first planner flow, day setup sheet, and workout notes are approved as-is.
  • NEW — macrocycles are the goal layer. Create flow (2.3) takes goal + duration + meso length and proposes a realistic, profile-based target, then lays out evenly-spaced mesocycles with suggested phases — unplanned until you reach them. "Slots" terminology retired; "macros" → "macrocycles" throughout.
  • NEW — Cycles restructure. Tapping a macrocycle opens the Overview (2.2: goal, target, progress, timeline, macro stats). Tapping a mesocycle opens the planner board (2.5) as a unified view/edit surface — past & active weeks lock, edits apply forward. Old meso-detail page retired.
  • Stats are contextual, no extra tab: macro stats on the Overview, meso stats (4.1–4.2 · balance & performance) behind the planner board's STATS toggle (2.5) — W3/W4 figures are the autoregulated plan, shown dim; orange marks the in-progress week. The old weekly-volume table was cut as duplicate of the balance view's planned-sets bars.
  • Unit sweep done — everything reads in lb now; kg stays one tap away in More → Settings.
  • More (4.4) proposes two rows beyond units + profile: AI connector and CSV export — cut either if premature. Appearance/dark mode intentionally omitted for now.
  • NEW — Library click-throughs filled in. Tapping an exercise (3.1) opens the full Exercise page with an OVERVIEW / HISTORY toggle (3.1a–b): group · type, last-performed, all-time bests (Weight PR, Est. 1RM, Volume PR shown as wt × reps, Best session vol), est-1RM-by-macrocycle, lifetime totals — and the full grouped history. "+ NEW" opens the exercise creator (3.1c: name, muscle group, equipment, track-per-set). "+ ADD MUSCLE GROUP" on day setup opens a region-grouped picker (2.6b).
  • Refined — 2.2 Macrocycle Overview. Orange pulled back to active/current markers only; copy tightened (target, progress axis, stats note). The 2.7 picker is now a uniform checkbox list — selection on the left, full history behind the ›, no inline set readout.
  • Round 5 candidates: clickable single-flow prototype stitching the screens together.
