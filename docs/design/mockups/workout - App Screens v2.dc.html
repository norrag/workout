workout — design exploration 03 · revision pass

Ledger system, rev. 2

Pump & workload are snap-to-stop sliders (no numbers — endpoints + ⓘ explainers). Set types: straight + drop. MESOS is now CYCLES, with macros as the expandable spine. The planner is now groups-first: lay out muscle groups and exercise counts for the day in one batch (2.5 Day setup — which also holds the day tools: label, weekday, week-start, remove), then fill each slot from a picker pre-filtered to that group with last-performed and history in view (2.6). Workout complete gains a free-text notes field, saved with the session for the AI connector and later analysis. Create-meso keeps the macro placement timeline; units live in Settings. Orange budget unchanged: current position + selected states only. Round 4: meso stats — volume, balance, performance — behind a stats button on meso detail; the More tab with profile & inline settings; and a full unit sweep to lb.
